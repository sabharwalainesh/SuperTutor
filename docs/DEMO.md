# Demo and submission checklist

## Build one real loop

1. Start API/workspace and the authenticated MCP bridge.
2. Confirm the Go connector and SuperTutor agent are installed and enabled.
3. In the workspace, create the sample loop assignment and save the unfinished code. Label the excerpt as sample material.
4. In Go, select SuperTutor and ask why the loop never finishes without requesting the finished function.
5. Show Go retrieving the actual work through a tool and asking a targeted question.
6. Answer with a plausible misunderstanding. Have Go record the attempt and a concept-specific hint.
7. Show saved feedback and progress appearing in the workspace.
8. Make a revision and show that the new attempt is preserved. Ask one short transfer question.

Do not say code was run, a lecture was watched, or a school account was synchronized unless that capability is actually implemented and demonstrated. Tutor judgments are not official grades. Finishing the demo alone does not establish improved learning.

## Fallbacks

The local workspace/API can run without internet, but the Go tutoring conversation needs the real Go service. If it is unavailable, show recorded evidence and disclose the limitation. Do not manufacture a fake Go conversation or present local SDK tests as a live sponsor integration.

A local read/write SDK test is useful debugging evidence, not the complete demo.

## Submission

Official page: https://mtc-x-grammarly.devpost.com/

- Select Productivity as the primary track.
- Explain the problem, student audience, and guided learning experience.
- Describe Go's central contribution and the custom MCP tools.
- Provide a short video showing both Go and the workspace.
- Include source/setup links that judges can access. Arrange access to the private repository.
- List all contributors and technology/pre-existing-work credits.
- Keep credentials, student private data, and bridge tokens out of the recording and repository.
- Deadline listed: **October 16, 2026, 8 PM Pacific**. The listed hacking window is 2:30–8 PM.
- Prepare a two-minute finalist pitch.

The event permits additional tools/APIs but requires the sponsor agents to be central. A purely standalone app demo is incomplete evidence for that requirement. Organizer decisions remain authoritative.
